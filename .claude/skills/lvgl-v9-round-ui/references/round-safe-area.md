# 圆屏安全区布局详解

## 几何模型

圆屏可视区 = 边长 `S=min(w,h)` 的正方形内切圆，半径 `R=S/2`，圆心 `(cx,cy)=(w/2,h/2)`。
四角（如 0.1w,0.1h 处）在圆外——矩形布局思维在圆屏上必然踩裁切。

## 角点校验算法

元素外接矩形 `[x, x+w]×[y, y+h]`，最远角点：

```
dx = max(|x - cx|, |x + w - cx|)
dy = max(|y - cy|, |y + h - cy|)
安全 ⇔ dx² + dy² ≤ (R - MARGIN)²        (MARGIN ≥ 4px)
```

放置即校验：中心在极坐标 `(ρ, θ)`、宽高 `w×h` 的元素，最坏情况半对角线
`hd = √((w/2)² + (h/2)²)`，要求 `ρ + hd ≤ R - MARGIN`。

## 常用安全带（S=466 为例，R=233）

| 区域 | 建议 | 说明 |
|---|---|---|
| 中心列（任何 y） | TOP_MID/BOTTOM_MID 对齐 | 水平居中永远安全；仅需校验垂直端点 |
| 顶部弧 | ρ ≤ 0.72R，角度 60°–120° | 角色头像、状态点 |
| 底部弧 | ρ ≤ 0.78R，角度 240°/300° | 左右对称按钮 |
| 左右弧 | ρ ≤ 0.80R，角度 ±30° 起 | 传感器点阵（dot 直径 ≈ 0.15R） |
| 标题 | y ≈ 0.02–0.09S | 字号 20–28pt 均安全 |

## 实测反例（本项目两次踩坑）

1. **角色头像水平排 y=11%**：角上点距心 235px > R=233 → DRUM/LEAD 被切。
   修复：改顶部弧 120°/100°/80°/60°，ρ=0.72R。
2. **文字用 BOTTOM_LEFT/RIGHT 对齐**：落在圆外被遮挡。
   修复：全部沿 240°/300° 弧摆放，长文本（tx 计数）缩短后居中放 0.80R。
