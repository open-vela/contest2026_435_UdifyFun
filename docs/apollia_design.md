# Apollia（海妖）— 可穿戴和弦/旋律乐器 + 圆屏 Hub 设计方案

> Contest 2026 · team 435 (UdifyFun) · 基于 BES2800BP (best1700_ep AOS EVB)

## 〇、名字与寓意

**Apollia**（阿波莉亚）—— 海妖 Siren 之名。

在希腊神话里，海妖的歌声能魅惑所有听见它的人，令水手心甘情愿驶向她的海域。
这款乐器以此为魂：

- **指环传感器 = 海妖的指尖**：每一次按压都是一段魅惑的音符
- **左手和弦是她的低吟，右手旋律是她的高歌**
- **Hub = 海妖的漩涡（Siren's Vortex）**：所有歌声汇聚于此，化作声呐涟漪涌向 DAW
- **多人协同 = 海妖合唱团（Siren Choir）**：鼓/铺底/节奏/主音/主唱各司其职，歌声交织
- UI 配色取深海：深渊蓝黑底、青绿声呐光、珊瑚色脉冲 —— 屏幕上永远有歌声向外扩散

> 产品口号：*"Play the song that lures the world."*（奏响魅惑世界的歌声）

## 一、产品概念

**Apollia** 是一套戴在双手上的电子乐器：

- 每只手 7 个带压感的**指环传感器**（环状，未来形态可演进为半指手套/全集成手套）
- 传感器**掌心面可按压+发光**（演奏反馈），**手背面仅发光**（角色/状态呼吸灯）
- **左手管和弦、右手管旋律**，双手配合即可演奏；IMU 体感调制效果器
- 多人通过 BLE 组网，各扮演鼓/铺底/节奏/主音/主唱角色合奏
- 圆屏 **Apollia Hub** 是数据中枢：聚合输入、可视化反馈、经 USB 输出 MIDI/OSC 控制 DAW

## 二、硬件形态

### 指环传感器（每手 7 个）

| 手指 | 关节 | 数量 |
|---|---|---|
| 食指 | 上关节（近指尖）+ 中关节 | 2 |
| 中指 | 上关节 + 中关节 | 2 |
| 无名指 | 上关节 + 中关节 | 2 |
| 小指 | 单关节 | 1 |

- 掌心面：压感（力度 0-127）+ RGB 发光（按下高亮 = 演奏反馈）
- 手背面：仅发光（呼吸灯 = 角色色/连接状态）
- 形态演进路线：独立指环 → 磁吸指环+手背扣 → 半指手套（布线内嵌）→ 全集成手套（柔性 PCB）

### 主机模块（电池 + 发射 + IMU）

佩戴位置二选一，**推荐手腕**：

| 位置 | 优点 | 缺点 |
|---|---|---|
| **手腕（推荐）** | 重心低、佩戴习惯自然、电池空间大、发热远离掌心 | 到指环需过一根柔性线 |
| 手背 | 走线最短、IMU 离手指近 | 贴合度要求高、手背出汗、影响握拳 |

IMU：6 轴（加速度计+陀螺仪），识别上下位移、握拳旋转等手势。

## 三、左手映射 —— 和弦

以 C 大调为例（可整体移调）。色码即 Hub 上的显示色。

| 传感器 | 级数 | 和弦 | 构成音 | 色码 |
|---|---|---|---|---|
| 食指·上关节 | I | C 大三 | C4 E4 G4 | 金 |
| 中指·上关节 | IV | F 大三 | F4 A4 C5 | 金 |
| 无名指·上关节 | V | G 大三 | G4 B4 D5 | 金 |
| 食指·中关节 | II | D 小三 | D4 F4 A4 | 靛 |
| 中指·中关节 | III | E 小三 | E4 G4 B4 | 靛 |
| 无名指·中关节 | VI | A 小三 | A3 C4 E4 | 靛 |
| 小指 | VII | B 减三 | B3 D4 F4 | 玫红 |

规律：**上关节 = 1/4/5 级大三和弦，中关节 = 2/3/6 级小三和弦，小指 = 7 级减三** —— 自然音阶内三种三和弦性质按关节分层，肌肉记忆直觉。

## 四、右手映射 —— 旋律

7 个传感器 = 自然音阶单音（C5 D5 E5 F5 G5 A5 B5），顺序同左手（食指上→食指中→中指上→…→小指）。青色系渐变显示。

## 五、IMU 体感

| 手势 | 识别方式 | 映射 |
|---|---|---|
| 手上下位移 | 加速度计 z 轴积分 | **效果湿度** wet/dry（MIDI CC91） |
| 握拳左右旋转 | 陀螺仪 yaw + 全传感器按下判定"握拳" | **效果器切换**（Program/CC20） |
| 握拳上下滑动 | 握拳状态 + 加速度计 | **效果强度**（CC1 调制轮） |

握拳检测：7 个压感全部 > 阈值 → 进入手势模式（此时指环不触发音符）。

## 六、多人协同 —— 海妖合唱团

- **连接**：BLE Mesh（>4 人）或 星型经 Hub 中继（低延迟演出场景）
- **角色**：鼓手(ch10 打击乐) / 铺底 Pad / 节奏 Rhythm / 主音 Lead / 主唱 Vocal(+效果控制)
- **Hub 职责**：BPM 时钟同步分发、角色分配、输入聚合、可视化、协议转换出 DAW

## 七、协议输出

| 协议 | 用途 | 状态 |
|---|---|---|
| USB MIDI 1.0 | Hub→电脑 DAW（本 demo 已实现） | ✅ |
| BLE MIDI | 手套→手机/Hub | 规划 |
| 内置合成器 | 脱机独立演奏 | 规划（HiFi4 DSP） |
| OSC (UDP) | 控制 Ableton/调音台 | 规划（WiFi 模块） |
| MIDI 2.0 | 未来工作台 | 预留 |

## 八、Apollia Hub（本 demo 范围）

圆屏 Hub 连接电脑，即"海妖的漩涡"：

1. **双手可视化**：14 个传感器以左右弧形排布，按下手柄高亮（模拟掌心灯）+ 常亮呼吸光晕（模拟手背灯）
2. **声呐涟漪（海妖之歌）**：核心持续向外扩散青绿声呐环；每条 MIDI 消息触发珊瑚色脉冲环 + 粒子从传感器飞入核心再涌向 DAW 口 —— 直观呈现"输入聚合→Hub 处理→输出"
3. **mock 输入**：触摸任意传感器 = 触发对应和弦/旋律，实时发 USB MIDI
4. **效果湿度**：上下拖动中心核心 = CC91（模拟 IMU 上下位移）
5. **乐器切换**：点击 INST = Program Change（模拟握拳旋转），钢琴/吉他/弦乐/合成器循环
6. **海妖合唱团**：顶部 4 个角色头像（DRUM/PAD/RHY/LEAD），点击=以该角色身份演奏（鼓=ch10），开机渐次点亮 = 玩家入网

### Demo 键位映射（MIDI）

- 左弧 7 点 → 上表和弦（ch1，按下发 NoteOn 全部构成音，松开发 NoteOff）
- 右弧 7 点 → 旋律单音（ch1，C5-B5）
- 角色 DRUM → ch10 底鼓(36)/军鼓(38)；PAD → Am 和弦；RHY → F 单音；LEAD → G5
- 核心纵向拖动 → CC91 湿度 0-127
- INST → PC 0/24/48/81

### 后续路线

真实指环传感器输入（BLE 接入）→ IMU 手势实装（BTH 核链路需完整 SDK）→ OSC 输出 → 内置合成器（HiFi4）→ MIDI 2.0。
